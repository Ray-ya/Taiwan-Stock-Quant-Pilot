## 🚀 快速開始

### 1. 安裝環境與套件
```bash
git clone https://github.com/Ray-ya/Taiwan-Stock-Quant-Pilot.git
cd Taiwan-Stock-Quant-Pilot
pip install requests pandas numpy beautifulsoup4
```

### 2. 執行單元測試 (驗證邏輯無誤)
```bash
python -m unittest discover tests
```

### 3. 生成最新台股量化晨報
```bash
python reporter/morning_reporter.py
```

### 4. 執行蒙地卡羅資金回測
```bash
python backtest/backtester.py
```

## ⏰ 自動化定時排程與開機補發

本專案支援整合系統排程 (Windows Task Scheduler / Cron)：
1. **每日 08:00 AM (台北時間)** 自動抓取昨日盤後資料與最新晨間即時新聞，計算當日三層選股與進出場點位。
2. **開機補發機制**：若 08:00 主機未開機，開機登入時會自動檢查今日晨報是否已生成，若未生成則立即執行並推播通知。
